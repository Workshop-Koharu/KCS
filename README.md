# KCS — Koharu Coding Server 공식 포털 (kcs.koharu.live)

Koharu Coding Server (KCS) 엔지니어링 스튜디오 및 커뮤니티의 모든 공식 소프트웨어 프로젝트를 소개하는 웹 포털입니다.

---

## 🚀 KCS 생태계 프로젝트 목록

1. **Sora (소라) — [sora.koharu.live](https://sora.koharu.live)**
   - Discord Components V2 기반 차세대 올인원 매니지먼트 & 4단계 보안 인증(Sendwich SMS, Resend 이메일, 캡챠, 버튼) 디스코드 봇.
2. **NextUps — [nextups.xyz](https://www.nextups.xyz)**
   - Windows, PlayStation, Nintendo Switch, Android, iOS 게임의 공식 최신 패치노트와 버전 정보를 통합 제공하는 게이밍 플랫폼.
3. **SnapBot — [snapbot.koharu.live](https://snapbot.koharu.live)**
   - Scratch / Entry 스타일의 블록 코딩으로 디스코드 봇을 만드는 제로 디펜던시 비주얼 IDE & 엔진.
4. **Aura AI**
   - 고성능 신경망 OCR 복원 및 분산 멀티모달 데이터셋 추론 파이프라인.
5. **Koharu Maps**
   - 인터랙티브 벡터 렌더링 및 고정밀 공간 데이터 시각화 맵 엔진.

---

## 🛠️ 기술 스택
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS + Lucide Icons + Glassmorphism UI
- **Deployment:** Vercel (`kcs.koharu.live`)

---

## 💻 실행 방법
```bash
npm install
npm run build
npm start
```
